# Аудиоплеер для Android

Универсальный плеер для лекций, уроков, чтения Корана и любых аудиозаписей.

## Возможности

- **Все аудио сразу** — плеер сам находит все аудиофайлы на телефоне (нужно один раз разрешить доступ).
- **Поиск** — строка поиска по названию и исполнителю во всех разделах.
- **Плейлисты** — создание, переименование, удаление; добавление треков по одному или «выбрать все найденные» по поиску; порядок «выше/ниже»; «Играть» и «Вперемешку».
- **Мини-плеер** внизу экрана, разворачивается по нажатию.
- **Плейлист** — добавление файлов с телефона, порядок «выше/ниже», удаление, перемешивание, повтор (весь список / один трек).
- **Скорость** 0.5× – 2× (запоминается).
- **Повтор A–B** — зациклить отрывок: нажать «A–B» в начале, «Точка B» в конце, «Сброс A–B» — выключить.
- **Продолжение с места остановки** — для каждого файла отдельно.
- **Закладки** — именованные метки внутри файла, переход одним нажатием.
- **Таймер сна** — 5–90 минут или «до конца трека», с плавным затуханием звука.
- **Поделиться / отправить файл** — в Telegram, WhatsApp и т. д.
- Работает в фоне, уведомление с кнопками, управление с экрана блокировки и наушников.
- Открывает аудио из других приложений («Открыть с помощью…» и «Поделиться → Аудиоплеер»).

## Как собрать APK

### Вариант 1 — с телефона через GitHub (без компьютера)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository).
2. Загрузите в него все файлы этой папки (Add file → Upload files), сохранив структуру папок.
   Важно, чтобы загрузилась и скрытая папка `.github`.
3. Откройте вкладку **Actions** — сборка запустится сама (около 5–7 минут).
4. Откройте завершённую сборку → внизу раздел **Artifacts** → скачайте `AudioPlayer-apk`.
5. Распакуйте zip и установите `app-debug.apk` (разрешите установку из неизвестных источников).

### Вариант 2 — на компьютере в Android Studio

1. Установите Android Studio.
2. File → Open → выберите папку `AudioPlayer`.
3. Дождитесь синхронизации, подключите телефон и нажмите ▶ Run,
   либо Build → Build APK(s).

## Структура

```
app/src/main/java/com/audioplayer/app/
  MainActivity.kt      — экран, добавление файлов, отправка, синхронизация списка
  PlaybackService.kt   — фоновое воспроизведение, A–B, таймер сна, позиции
  Store.kt             — хранение списка, закладок, настроек
  ui/PlayerScreen.kt   — интерфейс (Jetpack Compose)
  ui/Theme.kt          — цвета
```

Технологии: Kotlin, Jetpack Compose, Media3 (ExoPlayer). Android 8.0 и выше.
